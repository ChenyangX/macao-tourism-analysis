Macao Tourism Recovery
Visitor composition, daily arrivals and non-gaming expenditure
English edition: 1 November 2026

READING ORDER
1. Project_Proposal.pdf: research questions, methods, findings and limitations.
   Project_Proposal.docx is the editable version. Team details, roles and the
   four-week schedule remain deferred at the team's request.
2. analysis.ipynb: daily arrivals, composition, distributions and calendar models.
3. spending_analysis.ipynb: quarterly expenditure and annual comparisons.
   Both notebooks include explanations, course references, saved outputs and figures.
4. Project_Review.txt: assessment of correctness, course fit and research depth.

FILES
- data/: six fixed input CSVs and the data dictionary in README.txt.
- analysis.py and spending_analysis.py: scripts matching the notebook code.
- protocol.txt: the fixed design, translated without changing the experiment.
- requirements.txt: the package versions used in the experiments.
- results/: 24 CSV tables and the model-selection record.
- figures/: 13 figures generated by the analyses.
- summary.json / summary.txt: daily results.
- spending_summary.json / spending_findings.txt: expenditure results.

RUNNING
Use Python 3.12. Extract the archive, then open a terminal in the project folder.
Installing dependencies needs internet access. The experiments then use the included
data without logging in to Moodle or downloading new observations.

macOS or Linux:
  python3.12 -m venv .venv
  source .venv/bin/activate
  python -m pip install -r requirements.txt
  python analysis.py
  python spending_analysis.py

Windows PowerShell:
  py -3.12 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe analysis.py
  .\.venv\Scripts\python.exe spending_analysis.py

For notebooks, use VS Code with its Jupyter extension or an existing Jupyter
installation. Select the same Python environment and run each notebook from its first
cell, with this project folder as the working directory. Reading saved outputs needs
no execution. Running a script refreshes tables, figures and summaries, but does not
refresh notebook outputs; run the notebook to refresh those.
Keep data/, protocol.txt and both scripts even if you only run the notebooks.
Rerunning overwrites generated results and creates manifest.json as a runtime record.
The share archive excludes prior execution logs, caches, working files and backups.
Recheck written interpretations whenever data or models change: prose does not update
automatically when code runs.

LANGUAGE AND DATA INTEGRITY
Project prose, code comments, generated explanations and figures are in English.
Original official data labels remain unchanged, including source_name_zh and source
location text. source_name_en provides English source labels. Do not overwrite official
observations merely to translate them. The English edition preserves the numerical
methods, model settings and fixed data snapshot.

INTERPRETATION
The daily series covers 3,287 dates; its 55,879 source rows share those dates and are
not independent visitor records. Expenditure consists of 16 city-quarter estimates.
Amounts are nominal MOP, exclude gaming and have not been adjusted for prices.
Ridge was selected using 2024 validation; OLS with trend had lower 2025 test error.
The 2025 data had already been viewed in EDA, so the entire study is not a blind test.
Adjacent days may be dependent; residual autocorrelation was not formally tested.
No causal effects or statistical significance are claimed.
