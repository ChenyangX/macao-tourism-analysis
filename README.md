# Macao Tourism Recovery and Spending Analysis

**University of Macau · CISC7204 Semester Project**

This project investigates Macao visitor arrivals, recovery patterns, source-market composition, accommodation type, and tourism spending using historical data and Python analysis.

## Repository contents

- `analysis.ipynb` and `spending_analysis.ipynb`: executable notebooks, including original outputs
- `analysis.py` and `spending_analysis.py`: Python implementations
- `data/`: source and prepared CSV data, with `data/README.txt`
- `figures/`: 13 exported figures
- `results/`: derived CSV metrics and JSON results
- `Project_Proposal.pdf`, `Project_Proposal.docx`, `Project_Review.txt`, and other project documentation
- `requirements.txt`: Python dependencies

## Usage

Install requirements with `pip install -r requirements.txt` and open the notebooks in Jupyter. Inspect the included data README and project protocol for source and processing details.

## Limitations

Historical observational data cannot establish causality; definitions and coverage may vary by source and year. Please consult the analysis and supporting documents when interpreting results.
